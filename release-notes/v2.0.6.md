Genzimnify 2.0.6 improves native correctness, debugging, dependency restoration, and Studio execution controls.

### Added

- Native runtime call stacks with function names and source locations, including imported modules.
- `clock.monotonic()`, `luck.shuffle(stack)`, `luck.sample(values, count)`, and `math.isfinite/isnan/isinf`.
- `gzim update [name]` and `gzim install --locked`.
- `gzim-lsp --help` and `gzim-lsp --version`.
- Studio background execution for ordinary programs, Stop, configurable time limits, prefilled standard input, a 100,000-character console limit, and a utilities example.

### Fixed

- Integer powers preserve precision; int64 arithmetic overflow and unsafe float-to-int conversion raise catchable errors.
- Native sleep waits and validates durations.
- LSP survives incomplete strings and clears diagnostics on document close.
- Python export helpers avoid collisions with user names.
- Lockfile commits override branch/tag references during restoration. Dependencies are fetched as a batch before installed copies are replaced.
- Imported functions resolve relative imports from their own source file; failed module initialization restores import context and removes the incomplete cache entry.
- File `readline()` normalizes CRLF/CR line endings and retains newlines and returns empty text at EOF.
- Studio recognizes rizzgame from-imports and display aliases, and yields in top-level for loops.

### Runtime notes

Native integers remain signed int64. Native timing is synchronous; async syntax executes eagerly without a concurrent event loop. Python exports and Studio use Python integer and asyncio semantics. Studio game previews use cooperative execution, so long blocking functions can delay Stop. Local path dependencies are copied from their current contents rather than pinned by content.

### Downloads

Archives contain `gzim`, `gzim-lsp`, and the bundled native raylib graphics backend. Available targets: macOS Apple Silicon, Linux x86_64, and Windows x86_64. Verify downloads using `SHA256SUMS`.
