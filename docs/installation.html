Get started

Install Genzimnify

Install the native gzim runtime and gzim-lsp language server. Release packages are self-contained and do not require Python or Nim.

Intel Mac support

Genzimnify 2.0.2 and newer no longer provide macOS x86_64 builds. Version 2.0.1 is the final release with an Intel Mac binary.

Homebrew on macOS

Tap the repository and build the current native release:

brew tap obliv1onis/genzimnify https://github.com/Obliv1onis/Genzimnify
brew install --HEAD genzimnify

Homebrew installs both gzim and gzim-lsp. Homebrew handles the Nim build dependency; installed programs do not require Nim.

macOS, Ubuntu, and Kali installer

curl -fsSL https://raw.githubusercontent.com/Obliv1onis/Genzimnify/master/scripts/install.sh | sh

The installer detects the operating system and CPU, downloads the latest release archive, verifies its SHA-256 checksum, and installs binaries into ~/.local/bin. GZIM_INSTALL_ROOT changes the destination.

GZIM_INSTALL_ROOT=/usr/local/bin sh install.sh

Windows 10+

Open PowerShell and run:

irm https://raw.githubusercontent.com/Obliv1onis/Genzimnify/master/scripts/install.ps1 | iex

The installer places the executables under %LOCALAPPDATA%\Genzimnify\bin and adds that directory to the user PATH. The updated PATH applies to new terminal sessions.

Manual installation

Download a release

Open the GitHub Releases page and select the archive matching the operating system and CPU.

Extract the archive

Move gzim and gzim-lsp (or the Windows .exe files) into an installation directory.

Add the directory to PATH

Shells and editors use PATH to locate the runtime.

Verify the installation

gzim --version
gzim doctor

The output includes version 2.0.6, runtime: native Nim (Python-free), and the detected platform.

Release archives vs. source builds

Release archives require no development toolchain. Homebrew --HEAD and source builds compile Genzimnify with Nim first, but the resulting runtime remains independent.

Build from source

git clone https://github.com/Obliv1onis/Genzimnify.git
cd Genzimnify
nimble build -d:release
./gzim doctor
