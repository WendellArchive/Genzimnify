Genzimnify documentation

Genzimnify is a native, dynamically typed programming language with Python-like semantics and its own syntax. Source files use the .gzim extension and execute through the gzim runtime.

What “native” means

The gzim executable contains the lexer, parser, semantic analyzer, and runtime. Running gzim app.gzim does not generate a Python file or launch Python. Python starts when code imports a py.* module or an exported Python file is executed.

Runtime components

gzim doctor reports the installed runtime version and platform. Release packages include compiled executables and do not require Nim.
