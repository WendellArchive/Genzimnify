Editor and language server

gzim-lsp gives desktop editors language-aware diagnostics and navigation. It ships beside gzim in every release package.

Language server features

Syntax and semantic diagnostics update after document changes. Incomplete strings produce diagnostics without stopping the server; closing a document clears its diagnostics.

Verify the server

gzim-lsp --help
gzim-lsp --version

These commands print information and exit. Most editors start the server with no arguments over standard input/output. Ensure the installation directory is on PATH.

Zed

Other LSP editors

Configure gzim-lsp as a stdio language server for files matching *.gzim. The server follows the standard JSON-RPC Language Server Protocol.

{
  "command": "gzim-lsp",
  "filetypes": ["gzim"],
  "rootPatterns": ["gzim.toml", "genzimnify.nimble", ".git"]
}

Browser Studio

Open Studio to edit and run Genzimnify in your browser. It has syntax highlighting, completion, diagnostics, examples, and a console. Its rizzgame workspace splits the lower panel into a terminal on the left and a live Canvas preview on the right; see the step-by-step tutorial. The installable toolchain remains the authoritative native runtime.

Studio run controls · 2.0.6

Ordinary programs execute in a background worker. Press Stop or Ctrl/⌘ + Enter again to terminate execution, including infinite loops. Set Time limit to 10, 30, or 60 seconds, or None; the default is 10 seconds and runtime loading is excluded. The console stops at 100,000 characters. Open Program input in the console and enter one line per yap back call before running; exhausted input raises EOF. These input lines also work in game previews.

Stopping or timing out an ordinary program discards that worker's Python state and virtual files. Game previews use cooperative top-level loops and frame presentation; a long blocking function inside a game can delay Stop. Choose None to play longer games. Serve a local Studio over HTTP with python3 -m http.server; background workers cannot reliably load from file URLs.

Tree-sitter grammar

The grammar under grammars/genzimnify/ can be embedded by editors that support Tree-sitter. Regenerate parser sources after changing grammar.js:

cd grammars/genzimnify
tree-sitter generate
